AI-Agent工程学习-实现框架对比

发表于 2026-07-22 更新于 2026-08-20 分类于 计算机
八框架全体对比：主路径 LangChain / LangGraph / Deep Agents / CrewAI + 巡览 OpenAI Agents / MAF（AutoGen 沿革）/ LlamaIndex / Google ADK；附表 Claude/Mastra/PydanticAI；唯一 canonical 选型文档。

接 外部框架巡览（四） 与 Agent 工程化 · 自检：主路径四框架、生产工程层与外部四框架巡览均已齐；本篇是 主四 + 外四（MAF 口径）唯一 canonical 全体对比（另附 Claude/Mastra/PydanticAI 认名）——各系列正文只回链此处，不另建「对比（二）」。

0. 本文档在学习路径中的位置

阅读顺序说明： 建议学习顺序为「主路径四框架 → Agent 工程化 → 外部框架巡览 → 回看本文选型」。本文 permalink 日期可能早于巡览/工程化（排期所致），请按文末导航与系列链接阅读，勿按时间线跳读。

前置已学：

  • LangChain（一）～（六） — 薄 Harness、create_agent、Middleware
  • LangGraph（一）～（六） — StateGraph、Checkpoint、Interrupt、Multi-Agent
  • Deep Agents（一）～（五） — 厚 Harness、create_deep_agent、Subagent
  • CrewAI（一）～（五） — Flow + Crew、Role/Task/Process
  • Agent 工程化（一）～（四）+ 自检 — Runtime / 观测 / 韧性 / 部署
  • 外部框架巡览（一）～（四） — OpenAI Agents / MAF（AutoGen 沿革）/ LlamaIndex / Google ADK

理论锚点：

  • Agent（三）§6 Harness — Harness 定义与分层
  • Agent（六）§7 谱系 — 概念层 Harness 形态
  • Agent（四）§6 发版 Checklist — 评测与回归 canonical
  • Multi-Agent（五）§4 — 理论→主三框架映射（产品层全体选型以本篇为准）

垂直能力（不在框架主表展开）： RAG 系列 · MCP 系列

本文不做： API 分步教程、RAG/MCP 协议细节、外部框架第二套深讲（见巡览系列）。

0.1 主路径 vs 巡览路径

路径 框架 本课程角色
主路径（默认实现线） LangChain / LangGraph / Deep Agents / CrewAI 深讲 + 工程化；默认交付选型
巡览路径 OpenAI Agents SDK / MAF（AutoGen 沿革）/ LlamaIndex / Google ADK 认名 + 映射；借鉴模式，不默认换栈

universal（与框架无关）： LE Gate、Handoff 合同、幂等、租户隔离、Agent（四）§6、工程化 Runtime/观测/韧性/部署口径。

1. 一句话定位（官方口径）

1.1 主路径四框架

框架 官方定位 文档
LangChain minimal, highly configurable agent harness：create_agent = Model + Tools + Prompt + Middleware LangChain overview
LangGraph Low-level orchestration framework and runtime：durable execution、streaming、HITL、persistence LangGraph overview
Deep Agents Pre-assembled thick harness on LangGraph：planning、filesystem、subagents、memory 开箱 Deep Agents overview
CrewAI Flow（backbone）+ Crew（intelligence） CrewAI Introduction

生态关系（关键）：

  • Deep Agents ⊂ LangChain + LangGraph 生态（编译为 LangGraph Runnable）
  • CrewAI 是 并行实现线，不建立在 LangGraph 之上
  • LangGraph 是 LangChain 生态内的 编排 Runtime 底座

1.2 巡览四框架

框架 巡览定位 入口
OpenAI Agents SDK OpenAI 生态轻量 Agent Runtime：Tool 环 / Handoff / Guardrails 巡览（一）
MAF Microsoft Agent Framework；沿革含 AutoGen GroupChat/UserProxy 巡览（二）
LlamaIndex 索引与 Query 中心；RAG Agent / Query Engine 巡览（三）
Google ADK 开源 Agent 开发套件；可接 Google Cloud 托管 Runtime 巡览（四）

1.3 LangChain 官方三层产品 taxonomy

官方称谓 对应产品 中文含义
Agent framework LangChain Agent 开发框架：Model / Tool / Prompt / Middleware 组装
Agent runtime LangGraph Agent 运行时：状态图、持久执行、HITL、Checkpoint
Agent harness LangChain create_agent（薄）· Deep Agents（厚） 完整 Agent 工作环境

读法： Framework 提供零件；Runtime 提供编排引擎；Harness 打包可跑 Agent。CrewAI 与巡览四套 不在此三层内，属并行或生态绑定路线。

1.4 一句话记忆（选型速查）

框架 记忆口诀
LangChain Agent 开发工具箱（薄 Harness）
LangGraph Agent 工作流运行时 / 状态机引擎
Deep Agents 开箱长任务厚 Harness
CrewAI AI 团队 + 应用 Flow 框架
OpenAI Agents OpenAI 官方工具环 + Handoff
MAF Microsoft 现行 SDK；对话式多 Agent 沿革
LlamaIndex 检索与 Query 框架面
Google ADK 开源套件 + 可选云托管 Runtime

1.5 附表认名（不深讲）

名称 定位 何时看 本课为何不深讲
Claude Agent SDK Anthropic / Claude 原生工具环与会话恢复 已锁定 Claude、要官方 harness 厂商绑定；主路径不换
Mastra TypeScript 全栈 Agent 框架 TS/前端一体交付 本课 Python/主路径优先
Pydantic AI 类型安全 Python Agent 强依赖 Pydantic 校验输出 认名即可；编排仍常回 LG

AutoGen： 维护模式；模式见 巡览（二） 沿革节，新项目默认入口写 MAF。

2. 分层架构（自上而下）

先澄清常见误区： 框架 不是「哪个更好」的平级竞争，而是 不同抽象层的组合件。

读图注意： CrewAI 与 LangChain 生态 并列，不是 LangGraph 之上的一层。巡览栈通常自带 Runtime+Harness 打包，与上图再并列，而非插入 LangGraph 层之下。

读图口诀：

  • 要 精细图 + 确定性步骤 → 下沉 LangGraph
  • 要 单 Agent 可控外壳 → LangChain
  • 要 长任务开箱治理 → Deep Agents
  • 要 多角色产品化应用 → CrewAI Flow + Crew
  • 要 借鉴外部模式 → 读巡览，默认不换主路径

3. 核心抽象对照

3.1 主路径

维度 LangChain LangGraph Deep Agents CrewAI
中心 API create_agent StateGraph.compile() create_deep_agent Flow + Crew.kickoff()
思考单位 Agent loop + middleware State / Node / Edge 预装 middleware 栈 应用流程 + 角色团队
配置风格 Python 为主 Python 手画图 Python + Profiles JSONC + Python
抽象层级 中（Harness） 低（Runtime） 中高（厚 Harness） 高（应用框架）

3.2 巡览四框架

维度 OpenAI Agents MAF LlamaIndex Google ADK
中心抽象 Agent + Tools + Handoff Conversation / GroupChat Query Engine / Workflow Enterprise Runtime
强项 OpenAI 生态开箱 多角色对话原型 索引与查询管线 云企业治理与部署
典型缺口 图级精细弱于 LG 可审计门禁弱 编排弱于 LG 多云/开源可控性

3.3 开发体验与复杂度（主路径）

目标 上手最快 复杂系统可控性最高
简单单 Agent + 少量 Tool CrewAI / LangChain LangChain
复杂多步 + 分支 + 恢复 — LangGraph
长任务开箱（FS/规划/Subagent） Deep Agents Deep Agents
多角色产品化应用 CrewAI CrewAI Flow 层

4. 控制流与执行模型

4.1 主路径默认执行形态

框架 默认循环
LangChain Model → tool_calls → execute → ToolMessage → …
LangGraph 按边遍历 Node
Deep Agents planning → tools → FS → 可选 subagent → 汇总
CrewAI Flow @start/@listen；子步 crew.kickoff()

4.2 巡览对照

框架 控制流印象
OpenAI Agents 工具环 + Handoff 切换 Agent
MAF 工作流/多 Agent 编排；沿革消息轮次 + Speaker selection
LlamaIndex Query/Workflow 步
Google ADK 平台工作流 / Agent 编排（云侧）

4.3 Middleware / Hooks（主路径）

  • LangChain：Middleware 插在 agent loop
  • LangGraph：Middleware 进 agent 节点；图逻辑用 Node/Edge
  • Deep Agents：默认 Middleware 栈
  • CrewAI：Task Guardrail + Flow 装饰器

5. 多 Agent 模式对比

5.1 主路径

框架 多 Agent 表达 典型模式 强项
LangChain 非主战场 多 agent + 外部 LangGraph 单 Agent 闭环
LangGraph Supervisor / Subgraph / Handoff 图级显式路由 控制最细、可审计
Deep Agents task() Subagent 委派 + context quarantine 长材料隔离
CrewAI Role + Task + Process sequential / hierarchical 角色化协作

理论映射表：Multi-Agent（五）§4。

选型口诀： 图级门禁 → LangGraph；context 卫生长任务 → Deep Agents；角色流水线 → CrewAI。

5.2 巡览

框架 多 Agent 印象 理论映射
OpenAI Agents Handoff 专员 Handoff 合同
MAF 多 Agent 协作（沿革 GroupChat）/ Peer Debate / Peer
LlamaIndex 非多 Agent 主战场 偏单查询/RAG Agent
Google ADK 企业内多 Agent 产品抽象 视文档；对照 Supervisor/Crew

6. 状态、持久化、恢复

6.1 主路径

框架 机制 关键概念 强度
LangGraph Checkpointer thread_id、interrupt()、Command(resume=…) 最强
LangChain 透传 checkpointer create_agent(..., checkpointer=…) 可用
Deep Agents 消费 LangGraph Runtime FS/subagent 借底层
CrewAI Flow @persist restore / state id 应用层

生产存储与 /resume：工程化（一）（四）。

6.2 巡览

框架 印象
OpenAI Agents Sessions；对照 thread_id
MAF 会话/工作流状态（以文档为准）；精细恢复仍常对照 LG Checkpoint
LlamaIndex 索引持久 ≠ Agent run Checkpoint
Google ADK 企业会话持久（平台）

7. Context / Memory / Knowledge

7.1 主路径

框架 Context 治理 Memory Knowledge/RAG

7.2 巡览

LlamaIndex 检索/索引主场；评测回链 RAG 系列

8. Tools / MCP / Structured Output

8.1 主路径

8.2 巡览

11. 选型决策树

11.1 按场景首选（主路径）

场景 首选 备选 通常不推荐
聊天 / FAQ + 2～5 Tool LangChain LangGraph 单节点 Deep Agents / CrewAI
复杂分支 + 精细 checkpoint LangGraph CrewAI Flow 纯 LangChain
企业流程自动化 LangGraph CrewAI Flow + HITL 纯 Crew sequential
长任务 + FS/Subagent Deep Agents LangGraph 自建 纯 CrewAI
多角色产品化流水线 CrewAI LangGraph Supervisor Deep Agents alone
固定 ETL + 偶发 LLM LangGraph CrewAI Flow Crew

11.2 何时借鉴外部 / 何时不换栈

信号 动作
团队已锁定 OpenAI 官方 SDK 心智 可借鉴 Agents SDK；治理仍按工程化
需要 快速多角色对话原型 可借鉴 MAF / 历史 GroupChat 模式；Azure 栈可评 MAF；生产门禁用 LG/CrewAI
团队以 LlamaIndex 索引栈 为中心 框架面用 LI；评测仍走 RAG 系列
已绑定 Google Cloud 要托管一站式 可评估 ADK
要图级可审计、多云、开源可控 不换栈，主路径 LC/LG/DA/CrewAI
仅缺某一模式（Debate/Handoff） 借鉴模式，用主路径实现，不必引入整栈
