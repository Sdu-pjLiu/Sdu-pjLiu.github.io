AI-Agent工程学习-外部框架巡览(一)

发表于 2026-07-23 更新于 2026-08-20 分类于 计算机
外部框架巡览：OpenAI Agents SDK 的 Tool Calling Runtime、Handoff、Guardrails；与主路径对照。

接 Agent 工程化 · 自检与面试：生产工程层已齐；本系列 巡览 主路径外的四套框架——只建立心智模型与映射，不替代 LangChain / LangGraph / Deep Agents / CrewAI 默认实现线。

0. 巡览系列定位

篇 框架 焦点
（一） OpenAI Agents SDK Tool Runtime / Handoff / Guardrails
（二） MAF（AutoGen 沿革） Microsoft Agent Framework；GroupChat/UserProxy 模式映射
（三） LlamaIndex RAG Agent / Query Engine
（四） Google ADK 开源开发套件 + 可选云托管 Runtime

裁剪说明： Haystack 等仍不进巡览四篇。Claude Agent SDK / Mastra / Pydantic AI 仅在 实现框架对比 附表认名，不另开巡览篇。Semantic Kernel 并入 MAF 沿革（见巡览二），不再单列深讲。

本篇不做： 完整 API 教程、迁移指南、宣称换栈。

1. 一句话定位

OpenAI Agents SDK： 面向 OpenAI 生态的轻量 Agent 运行时——把 Agent + Tools + Handoff + Guardrails 组装成可跑环，强调会话与追踪开箱体验。

官方文档随版本演进；学习时抓住抽象名，细节以当时文档为准。

2. Tool Calling Runtime

维度 内容
环 模型提出 tool_calls → 运行时执行 → 结果回灌 → 再推理
与主路径 同构于 LangChain create_agent 工具环；治理挂运行时而非仅 Prompt
工程要点 Schema 校验、超时、幂等写工具——回链 工程化（三）

3. Handoff

维度 内容
含义 控制权交给另一 Agent（专员），携带必要上下文
理论映射 Multi-Agent（二） Handoff 合同：Goal、open[]/done[]、硬规则、证据指针
与主路径 类似 LangGraph handoff / Deep Agents subagent 摘要返回。治理要求须 Context 隔离（禁全文 Trace 灌窗）；注意 OpenAI SDK 默认 Handoff 常可带完整对话历史，隔离靠 input_filter 等显式配置，勿把「须隔离」误当成 SDK 默认行为

4. Guardrails

维度 内容
含义 输入/输出或工具前的确定性或模型辅助护栏
与主路径 对照 LangChain Middleware Guardrails、after_model / wrap_tool_call——LangChain（六）
边界 护栏 ≠ 替代 Runtime allowlist / HITL / LE Gate

5. Sessions 与 Tracing（补点）

能力 巡览口径
Sessions 多轮会话状态；对照主路径 thread_id + Checkpointer
Tracing 运行轨迹排障；对照 LangSmith / 工程化（二）

生产仍须自备租户隔离、成本账本与发版 Checklist——框架开箱 Trace 不自动等于 Agent（四）§6 达标。

6. 与主路径一行对照

概念 OpenAI Agents SDK 主路径落点
工具环 Tool Calling Runtime LangChain create_agent
交接 Handoff LangGraph handoff / DA subagent
护栏 Guardrails Middleware / LE Gate
会话 Sessions thread_id + Checkpointer
观测 Tracing LangSmith + 工程化（二）

选型口诀： 已锁定 OpenAI 生态、要官方 SDK 心智 → 可借鉴；默认交付与精细图编排 → 仍走 LangGraph 生态。全体表见 实现框架对比。

5. 沿革认名：Swarm / Assistants → Agents SDK

旧心智 现行口径
Swarm（实验手递） 能力收束进 Agents SDK 的 Handoff 叙事
Assistants API（托管线程） 平台侧演进；应用编排优先学 Agents SDK + Responses/工具环（细节以 OpenAI 文档为准）

巡览只抓：Agent + Tools + Handoff + Guardrails；不跟版号刷迁移清单。

总结

巡览焦点： Tool Runtime、Handoff、Guardrails；Sessions/Tracing 认名。

映射： 合同与隔离要求与 Multi-Agent / 工程化 universal 一致。
