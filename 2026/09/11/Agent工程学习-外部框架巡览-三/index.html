AI-Agent工程学习-外部框架巡览(三)

发表于 2026-07-23 更新于 2026-08-20 分类于 计算机
外部框架巡览：LlamaIndex 的 RAG Agent、Query Engine；与 RAG 系列边界；Workflow 认名。

接 外部框架巡览（二）：AutoGen 偏对话协作；本篇巡览 LlamaIndex——检索增强与 Query 抽象见长，Agent 能力建立在其 RAG 栈之上。

0. 本篇位置与边界（重要）

文档 职责
RAG 系列 检索质量、切分、评测、企业 ingestion——canonical
本篇 LlamaIndex 作为 框架面 的 Agent / Query Engine 认名

本篇不重写： RAGAS、切片策略、ACL、发版检索指标——一律回链 RAG 系列。

1. 一句话定位

LlamaIndex： 以 索引与检索编排 为中心的框架；上层提供 Query Engine、RAG Agent / Workflow，把「问文档」产品化。与 LangChain 同属应用开发层，但默认重心在数据与查询管线。

2. Query Engine

维度 内容
含义 对索引发起查询的统一入口：检索 →（可选压缩/重排）→ 合成回答
强项 多种索引与查询模式组合快
对照 主路径用 LangChain Retriever Tool / 自建 RAG 节点 + RAG（三） 等
工程 引用与空检索行为仍须 Gate——回链 LE / Agent（四）§6

3. RAG Agent

维度 内容
含义 在工具环中调用检索/查询引擎，多步改写 query、比对证据
风险 无评测的「Agent 化」掩盖检索差；假引用
对照 主路径：RAG Tool + LE Gate + 发版 Scenario；不必为 Agent 而 Agent

4. Workflow / Agent（认名）

LlamaIndex 后续用 Workflow 等表达多步控制流——概念上接近「轻量编排」。

需求 建议
复杂分支、HITL、精细 Checkpoint LangGraph
文档问答 / 索引实验快 LlamaIndex 可借鉴
检索评测与企业 ingestion RAG 系列，与框架无关

5. 与主路径对照

概念 LlamaIndex 本路径
查询入口 Query Engine Retriever + 合成节点 / Tool
检索 Agent RAG Agent create_agent + RAG Tool
编排 Workflow LangGraph / CrewAI Flow
评测 生态工具可选 RAG 系列 + Agent（四）§6

总结

Query Engine / RAG Agent 是巡览核心；评测与生产检索规范回链 RAG 系列。

不换栈理由： 主路径已具备 RAG+Harness；仅当团队以 LlamaIndex 索引栈为中心时借鉴。
