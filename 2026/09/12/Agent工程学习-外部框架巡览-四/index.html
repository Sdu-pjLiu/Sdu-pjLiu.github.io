AI-Agent工程学习-外部框架巡览(四)

发表于 2026-07-23 分类于 计算机
外部框架巡览：Google ADK 企业 Agent Runtime；与 LangGraph、工程化部署对照；收口至全体框架对比。

接 外部框架巡览（三）：LlamaIndex 偏检索框架面；本篇巡览 Google Agent Development Kit (ADK)——开源、code-first 的 Agent 开发套件，深度整合 Google Cloud 部署与治理；托管 Agent Runtime 是部署选项之一，而非「只等于云托管 Runtime」。

0. 本篇位置

巡览最后一篇。读完后进入 实现框架对比 做 八框架全体选型（主四 + 外四）。

产品名称与模块随 Google 文档更新；抓住 ADK（开发套件）vs 托管 Runtime（部署面） 即可。

1. 一句话定位

Google ADK： 开源多语言 Agent 开发框架——强调工具、会话、编排与（可选）云侧托管体验；精细可审计状态机仍可比 LangGraph，自托管栈对照 工程化（四）。

2. 能力面（开发套件 + 可选托管）

能力面 巡览口径
会话与状态 企业会话持久、多轮；对照 thread_id + Checkpointer
工具与集成 连接 Google 与企业系统；仍须 allowlist / 幂等
编排 多步 Agent / 工作流；精细可审计图仍可比 LangGraph
部署 可自托管，也可上云托管 Runtime；对照工程化自托管栈
观测与治理 平台日志/追踪；对照工程化（二）与 Agent（四）§6

3. 与 LangGraph / 工程化对照

维度 Google ADK 本路径
Runtime 哲学 企业平台封装 LangGraph 显式 StateGraph + 自建治理
HITL / 恢复 平台能力（以文档为准） interrupt + Checkpointer + /resume
部署 云托管优先 FastAPI + Worker + PG/Redis 或混合
多 Agent 产品内协作抽象 Supervisor / Crew / Subagent 已深讲
默认栈绑定 Google 生态深 模型与云可替换，主路径开源可控

口诀： 已绑定 Google Cloud 且要托管体验 → 可评估 ADK；要图级精细控制与多云 → LangGraph + 工程化。

4. 巡览系列收口

未收录说明： Semantic Kernel / Haystack 等未进本巡览四篇，属刻意裁剪，见巡览（一）。

总结

ADK = 开源开发套件（可接云托管）；对照而非替代主路径。

巡览结束 → 用对比文做最终选型，默认实现线仍是 LC / LG / DA / CrewAI。
