测试框架学习-Py与Go对照与实践清单

发表于 2026-08-03 更新于 2026-08-20 分类于 计算机
基础概念与 Py/Go 工具对照表，以及两边最小验收 checklist。

接 Go 自检与面试：本篇收口——基础概念与两侧工具映射，并用 checklist 验收。

0. 本篇位置

系列收官。入口：软件测试基础与工程实践。

1. 一句话定位

对照篇： 概念一一映射；清单要求「会设计 + 会用工具」两边都勾完。

2. 概念与工具对照

概念 Python Go
用例设计落地 parametrize table-driven + t.Run
运行器 pytest go test + testing
资源生命周期 fixture / yield t.Cleanup / suite
断言增强 原生 assert / approx Testify assert/require
替身 mock / pytest-mock / fake fake / GoMock
属性/模糊 Hypothesis FuzzXxx（加分）
HTTP 组件 （点到） httptest
覆盖率 pytest-cov -cover
竞态 隔离约定 -race

共享口诀：用例独立；能注入则注入；覆盖率是仪表盘；错误路径与 happy path 同权。细节见基础篇。

3. 最小实践清单

3.1 基础（无框架也可口述）

  • 能说明「单元 / 边界 / AB」不在同一轴（分层 × 设计 × 实验）
  • 能画测试金字塔并说明本系列主攻层
  • 对一个函数写出等价类 + 边界值（边界测试）+ 至少一条错误路径
  • 能区分冒烟与回归；能区分黑盒与白盒（认名）
  • 能区分 stub / mock / fake
  • 能说出 FIRST 与 AAA

3.2 Python（工具链）

  • parametrize ≥ 3 组含边界
  • 依赖注入 + mock（含一次 side_effect）
  • --cov + term-missing 能解释缺失
  • 至少一个 @given + @example（推荐）
  • 自检 S 题口述过半

3.3 Go（工具链）

  • table-driven + 子测试名
  • fake 或 GoMock：成功 + 错误路径
  • httptest.NewRecorder 断言 Code/body
  • -race、-cover 能解读
  • 自检 S 题口述过半

3.4 迁移自检

  • fixture scope ↔ Cleanup/helper
  • Recorder ↔「不启服务测 handler」
