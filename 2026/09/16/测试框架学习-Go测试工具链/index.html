1. 一句话定位与依赖

工具 作用
testing + go test 官方运行器；表驱动默认范式
Testify assert / require / 可选 suite
GoMock 按 interface 生成 mock + EXPECT
httptest Recorder / NewServer 测 HTTP

2. testing 与 go test

2.1 发现约定

  • 文件：*_test.go
  • 内部测试包：package foo——可测未导出符号
  • 外部测试包：package foo_test——只测公开 API，更接近用户
  • TestXxx(t *testing.T)；另有 BenchmarkXxx、ExampleXxx、FuzzXxx

2.2 常用命令

旗标 作用
-race 数据竞争
-cover 覆盖率摘要
-count=N 跑 N 次；1 常用于 bypass cache
-short 短模式
-timeout 单包超时

集成测可用 build tag（如 //go:build integration）或独立目录，避免拖慢默认 go test ./...。

2.3 TestMain 与 Cleanup

辅助函数加 t.Helper()，失败行号指向调用方。

3.3 Fatal vs Error

3.4 并行

4. Testify

4.1 assert vs require

4.2 常用断言（认名）

API 用途
Equal / NotEqual 相等
ElementsMatch 切片元素相同（忽略顺序）
Contains 子串/元素
Nil / NotNil 空值
Error / NoError / ErrorContains 错误
Eventually 条件在超时内变为真（异步点到）
Len 长度

4.4 suite（了解）

小型纯函数单测通常不必上 suite。

4.5 testify/mock vs GoMock

Testify 自带 mock；本系列生成向以 GoMock 为主。原则：面向接口、少绑实现细节。

5. GoMock 与可测设计

5.1 先接口

5.2 手写 fake vs GoMock

方式 何时
手写 fake 接口小、行为简单
GoMock 方法多、要严格次数/参数/次序

5.3 mockgen 与 EXPECT

常用：Any()、Times/AnyTimes、InOrder（严格次序，慎用）、Do/DoAndReturn、AssignableToTypeOf。
Controller 结束时校验未满足 EXPECT。

5.4 反模式

无接口硬 mock；EXPECT 过死；mock 被测逻辑本身。

6. httptest

6.1 NewRecorder

组装与生产一致的 mux/中间件链再 ServeHTTP。

6.2 NewServer

测自研 Client 时把 BaseURL 指到 ts.URL。StartTLS 点到即可。Client 应设超时，避免挂死。

6.3 与 mock 分工

目标 手段
Handler 合同 Recorder + fake service
Client 编解码/重试 NewServer
难启动 SDK GoMock/fake

6.4 单元 vs 集成

单元：Recorder + fake。集成：真依赖 + build tag，少而精。

7. Fuzz 点到（对照 Hypothesis）

与 Hypothesis 同属生成式找反例；本系列 Go 主线仍是 table-driven + httptest。

8. 叠用模板

  1. 纯函数：table-driven + require/assert。
  2. Service：接口 + fake/GoMock。
  3. Handler：Recorder + 中间件链。
  4. Client：NewServer。
  5. CI：go test -race ./...，cover 防回退。

9. 做什么 / 不做什么

工具 做 不做
testing 组织、表驱动、race/cover 替代用例设计
Testify 可读断言与停/不停 生产代码依赖
GoMock 严格交互隔离 无接口硬上、过死次序
httptest HTTP 进出边 替代下游 DB 集成

10. 常见坑

  1. 无 name / 无 t.Run。
  2. 该 Fatal 却 Error。
  3. 忽略 -race；NewServer 未 Cleanup。
  4. Recorder Code 为 0 未用 Result() 理解默认。
  5. EXPECT 过死；单测打外网。
  6. 未统一时强上 Ginkgo，丢失表驱动可读性。

总结

标准库 + 表驱动是骨架；Testify 理断言；GoMock 服务接口；httptest 覆盖 HTTP。概念回链基础篇。
