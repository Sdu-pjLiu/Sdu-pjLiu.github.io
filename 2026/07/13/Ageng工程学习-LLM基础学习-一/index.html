1. Transformer

什么是Transformer？

通俗来讲，Transformer是一种让AI理解一整段文本中所有词之间关系的神经网络架构。他最核心的能力是通过 Self-Attention（自注意力机制），让模型能够理解输入序列中不同 Token 之间的关系。

负责：理解输入 -> 建立上下文关系 -> 生成输出

主要解决的问题为：

  1. 长距离依赖。
  2. 并行计算
  3. 更容易拓展

2. Attention Mechanism

Attention Mechanism 是一种让模型动态决定当前 Token 应该关注哪些其他 Token的机制。简单来讲是模拟人的注意力的机制

Self-Attention（自注意力）

含义：一个序列内部：每个 Token 都可以关注其他 Token。

2.1 QKV 机制

Attention 的核心是 Query（Q）、Key（K）、Value（V）三个概念。

Query（Q）

表示：当前 Token 想寻找什么信息。

例如：“他”需要寻找——谁是这个人的信息。

Key（K）

表示：其他 Token 提供什么特征。

例如：“小明”提供——人物信息。

Value（V）

表示：Token 实际包含的信息。

例如：小明对应的具体语义内容。

2.3 Attention 数学机制

核心公式：

$$\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\left(\frac{QK^{T}}{\sqrt{d_k}}\right)V$$

其中：

  1. $QK^{T}$：计算 Query 与所有 Key 的匹配分数。
  2. $\sqrt{d_k}$：按 Key 维度缩放，避免点积过大导致 Softmax 梯度消失。
  3. $\mathrm{softmax}(\cdots)$：把分数转成和为 1 的 Attention 权重。
  4. 再与 $V$ 加权求和，得到新的 Token 表示。

计算过程：

  1. 计算 Q 和 K 的匹配程度。
  2. Softmax 转换为权重。
  3. 根据权重组合 Value。

结果：得到新的语义表示。

2.4 Attention 的计算复杂度

Self-Attention 的计算复杂度为 O(n²)，其中 n = Token 数量。

原因：每个 Token 都需要和其他所有 Token 计算关系。

例如：

  1. 1000 Token：需要 1000 × 1000 次关系计算。
  2. 100000 Token：需要 100000 × 100000 次关系计算。

2.5 Attention 优化技术

Flash Attention

一种对标准 Attention 做 IO 感知（IO-aware）优化的实现：不改变数学结果，而是通过分块计算、减少 GPU 高带宽显存读写，来加速 Softmax Attention。

作用：

  1. 降低显存占用
  2. 提高训练 / 推理速度

Sparse Attention

不再让每个 Token 与全部 Token 两两计算，而是只关注局部窗口、特定稀疏模式或重要位置上的 Token。

**作用：**减少无关位置的计算，降低长序列下的计算量。

Linear Attention

通过改写 Attention 中的 Softmax / 核函数形式，把「Token 两两交互」近似成可线性累加的计算，使复杂度从 O(n²) 降到接近 O(n)。

**作用：**在更长上下文场景下控制计算与显存开销（通常会有一定精度折中）。

KV Cache

自回归生成时，历史 Token 的 Key / Value 不会变；把它们缓存下来，新 Token 只需计算自己的 Q，并与已缓存的 K、V 做 Attention。

**作用：**避免重复计算历史状态，显著提升逐 Token 生成速度。

关系：

  1. Transformer 是整体架构。
  2. Attention 是 Transformer 的核心计算模块。
