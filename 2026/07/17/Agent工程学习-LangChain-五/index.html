发表于 2026-07-17 分类于 计算机
create_agent 最小闭环、response_format、checkpointer 短时记忆、Streaming；与 LE 停止条件对齐；AgentExecutor 仅作历史。

接 LangChain（四）：积木可挂 Tool 之后，进入本系列核心——create_agent：官方推荐的 Agent harness。

0. 本篇位置

官方：Agents。

1. 最小 Agent

要点：

  • 输入更新 State（至少含 messages）。
  • 循环：模型 →（有 tool_calls 则执行并追加 ToolMessage）→ 再模型，直至不再调工具或被门禁打断。
  • 返回值是状态字典；读最终回复看 messages 末条。
  • create_agent 产物是 Runnable：与 LCEL 链、LangGraph 图一样，可 invoke / stream（见 §4）。

1.1 一次 invoke 的消息轨迹

以「查上海天气」为例，一次完整 invoke 后 messages 的典型快照：

对应 Agent Loop 语义：

消息序号 Loop 环节 说明
[0] 用户输入 Goal 进入 State
[1] Action 模型选出 get_weather
[2] Observation 工具结果写回；下一轮 Inference 可见
[3] Final Answer 无 tool_calls，harness 默认结束本轮

若 [3] 仍带 tool_calls，环会继续；若配置了 response_format，同时可读 structured_response。

2. 结构化输出：response_format

  • 官方在支持时走 ProviderStrategy（原生结构化），否则 ToolStrategy（用 tool calling 拿到结构）。
  • 与 LE 可机检合同 对齐：字段可校验，优于「模型宣称写好了」。

详见 Structured output。

3. 短时记忆：checkpointer + thread_id

多轮对话需要持久化 messages：传入 checkpointer，调用时带同一 thread_id。

概念 作用
checkpointer 把线程状态落到内存/数据库
thread_id 会话隔离键
state_schema 扩展 AgentState 自定义字段（认名）
store 跨线程长期记忆（认名；深挖可后置）

文档：Short-term memory。生产环境用持久化 checkpointer，不要只用 InMemory。

context_schema（三）与 thread_id 常一起用：前者 per-run 配置，后者会话历史。

4. Streaming

长任务需要中间态：Agent 编译图底层与 LangGraph 共享 streaming 机制（见 LangGraph（四））。

API 用途
agent.stream(..., stream_mode=...) 按模式输出 state 增量或 LLM token
agent.stream_events(..., version="v2") 细粒度事件（tool、interrupt、子图）

常用 stream_mode：

模式 输出
updates 每个节点产生的局部 state 更新
values 每步后的完整 state
messages LLM token + metadata 元组

用途：UI 进度、日志、提前取消。原则是 不要等整轮结束才第一次吐字。

5. 与 Loop Engineering 对齐

create_agent 提供「能循环」；何时算成功/失败/放弃仍要你设计：

LE 概念 在 LangChain 中的落点
可机检 Done response_format、工具后置校验、测试
验证门 Middleware / 确定性检查 / HITL（六）
硬顶预算 call limit middleware、外层超时
禁止仅靠自评关环 不要把「模型说完成」当唯一停止条件

Harness 默认「无 tool call 则停」≠ 业务合同满足；业务 Done 要显式验收。

6. 历史：AgentExecutor（勿用于新代码）

旧教程中的 AgentExecutor / initialize_agent 属于 LangChain 0.x 路径。

  • 读遗留代码时能认即可。
  • 新项目统一 create_agent；扩展用 Middleware，而不是堆 Executor 回调。

总结

主路径：create_agent(model, tools, system_prompt)。

结构：response_format → structured_response。

记忆：checkpointer + thread_id；可选 state_schema / store。

流式：stream / stream_events 暴露中间态。

LE：循环能力 ≠ 收敛合同；门禁与预算用 middleware / 外层治理。

历史：AgentExecutor 不作为新代码主路径。
