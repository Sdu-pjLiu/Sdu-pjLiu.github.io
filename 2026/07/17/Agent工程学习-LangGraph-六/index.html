AI-Agent工程学习-LangGraph(六)

发表于 2026-07-17 分类于 计算机
Subgraph、Router/Supervisor、create_agent 入图、Multi-Agent、实践阶梯；收口至 Deep Agents。

接 LangGraph（五）：Interrupt 与 LE 对齐之后，用 Subgraph 与多 Agent 模式 拼装企业拓扑，并收口本系列。

0. 本篇位置

前四篇：Graph / State / Persistence / 执行；第五篇：可控运行。

本篇：模块化 + 模式 + 与 LangChain 拼装 + 实践阶梯。

官方：Subgraphs

1. Subgraph

把一段流程编译成 子图，作为父图的一个 Node 嵌入。

checkpointer=（子图 compile） 行为（认名）
None（默认） 单次调用内 fresh；单次调用内可 inherit 父 checkpointer 支持 interrupt
True 同 thread 跨调用累积子图状态
False 无 checkpoint；像纯函数，无 interrupt/durable

父图 必须 带 checkpointer，子图的 interrupt / 持久化才完整生效。

跨子图共享数据：优先 Store；或设计 state 映射（子图更新未必立刻反映父 checkpoint 命名空间）。

2. Router 与 Supervisor

模式 结构 适用
Router 分类节点 + conditional edge 到不同分支 意图分流、模型/工具集切换
Supervisor 中心节点分派到专家子图/子 Agent 研究/编码等多角色

Supervisor 伪拓扑：

Handoff 必带（回 Agent 六）：Goal 摘要、已完成/未完成、硬规则引用。

Swarm（多 Agent 对等协作）：行业模式名；LangGraph 无单独「Swarm API」——用多节点 + Store + 路由实现即可；非入门主线。

以下假定 model 与 tools 已按 LangChain（三） 定义：

选择 适合

手画 ToolNode 环 在模型/工具之间插验证、审批、改写、独立预算节点

无论哪种，都应配 recursion_limit 与业务停止条件。

Superstep 节点 state 变化

6. Multi-Agent 落地要点

  1. Context 隔离：子 Agent 各用 subgraph / 独立 messages 切片，防互相污染。
  2. 统一 Store：跨 Agent 共享用户级事实。
  3. 统一 thread 或分 thread：按产品需求；审计场景常分 thread + Store 汇总。
  4. LE 门禁在图级：外环验证节点 + 预算 state，不单靠子 Agent 自评。

7. 实践阶梯 L0 → L2

级别 做什么 证明
L0 线性 DAG + 明确 recursion_limit Node/Edge/compile；能解释触顶行为
L1 + checkpointer 多轮 + interrupt；用 Send 并行处理 N 条输入 Persistence + HITL + 动态并行
L2 Supervisor + 两个 Agent 子图（create_agent 或 ToolNode 环）+ 验证节点 + trace 企业拓扑 + LE 对齐

8. LangSmith（轻量）

  • LANGSMITH_TRACING=true：看 节点级 路径、state 转移、interrupt 载荷。
  • 图比单 Agent 更依赖 trace：定位「哪条边走错」。
  • 部署认名：LangSmith Deployment / Agent Server（平台篇，此处不展开）。

9. 全路径与下一模块

需求 去向
标准单 Agent + Middleware LangChain
自定义编排 + durable + HITL LangGraph（本系列）
开箱 FS / Skills / subagent 栈 Deep Agents

除本系列主讲的 Graph API 外，Functional API（@entrypoint / @task）可在保留函数式结构时获得同一 Runtime 能力；两者可混用，回看（一）。

总结

Subgraph：模块化；checkpoint 作用域要显式选。

Router / Supervisor：分流与分派；Handoff 带摘要与规则。

拼装：create_agent 整段入图。

工具环：ToolNode + tools_condition 提供细粒度拓扑控制。

Multi-Agent：隔离 + Store + 图级 LE 门禁。

阶梯：L0 DAG → L1 持久/HITL → L2 Supervisor 拓扑。
