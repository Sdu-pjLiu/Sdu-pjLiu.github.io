AI-Agent工程学习-LangChain(三)

发表于 2026-07-17 更新于 2026-07-20 分类于 计算机
Agent 侧 system_prompt 与 Chain 侧 Prompt 模板；@tool / StructuredTool；ToolRuntime 与 context_schema。

接 LangChain（二）：会拼 Runnable 之后，补齐 输入合同（Prompt） 与 动作合同（Tools），以及工具如何读运行时上下文。

0. 本篇位置

场景 Prompt 怎么写 工具怎么挂
Agent（主） create_agent(..., system_prompt=...) tools=[...]
Chain / RAG（辅） ChatPromptTemplate + LCEL 检索器或函数进管道

动态改 prompt / 可用工具列表 → 优先 Middleware（见六），而不是把模板写成巨型静态字符串。

回链：PE 一 · 组成、LLM 四 · Tool Calling、Agent 三 · 工具治理。

1. Prompt：Agent 侧 vs Chain 侧

1.1 Agent 侧（主）

  • 接受 str 或 SystemMessage。
  • 运行时对话进 messages；系统指令与用户轮次分离（对齐消息角色）。

1.2 Chain 侧（辅）

组件 作用
PromptTemplate 字符串模板（{variable}）
ChatPromptTemplate 多角色消息模板
MessagesPlaceholder 插入历史消息列表（如 chat_history）

Few-shot 模板：认名即可；版本与评测回 PE 三。

2. 输出：Structured Output 优先

方式 何时用
Agent response_format= Agent 最终要返回 Pydantic / schema（见五）
with_structured_output 单次 ChatModel 调用就要结构
经典 OutputParser 读旧代码；新链路优先 schema 校验

「解析自然语言当合同」脆弱——与 LE · 可机检合同 同一原则。

3. Tool：@tool / StructuredTool

3.1 定义

要点（对齐 Agent 五 · 能力膨胀）：

  1. name：默认函数名；HITL / 权限档按 name 匹配。
  2. description：模型选型最敏感——何时用 / 何时不用要写清。
  3. 参数类型注解：生成 JSON Schema；含糊描述 = 错调工具。

也可用 StructuredTool.from_function 显式构造；本质都是 BaseTool。

3.2 错误与副作用

  • 工具内抛错：应变成可观察的失败信息，供模型重试或换策略（环内再配 ToolRetry Middleware）。
  • 有副作用的工具：审批档与 HITL 见 Agent 六、六 · HumanInTheLoop。

4. Runtime Context：工具如何读上下文

Agent 可声明 context_schema，调用时传入 context=；工具通过 ToolRuntime（或等价 runtime 参数）读取——用户 ID、租户、功能开关等 不应塞进 Prompt 明文 时可走这条路。

工具也可按文档约定 写回短时状态（更新 messages 外的自定义 state 字段）——细节以当前版本文档为准；原则是：状态变更显式，不靠隐藏全局变量。

5. Toolkit 与 MCP→Tool（认名）

概念 作用
Toolkit 一组相关工具的打包（社区集成常见）
MCP → Tool 外部能力总线暴露的动作，映射进 Tool Calling 闭环

MCP 认名见 Agent 六：执行仍走 schema → 调用 → ToolMessage；LangChain 侧负责把 MCP 工具适配成 @tool / BaseTool。

动态裁剪可用工具集合（防目录膨胀）→ Middleware / 按需注入，对齐 Agent 五 L2 加载。

本模块自检与面试

学完本篇后，请到 LangChain · 自检与面试 完成学习自检与面试题（含推荐回答）。

总结

Prompt：Agent 用 system_prompt；Chain 用 Template + Placeholder。

输出：结构化 schema 优先。

Tool：@tool + 清晰 description + 类型注解；副作用要闸门。

Runtime：context_schema + ToolRuntime 读上下文；状态显式。

MCP/Toolkit：认名；执行仍是 Tool Calling。
