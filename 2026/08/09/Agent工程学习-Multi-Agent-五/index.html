AI-Agent工程学习-Multi-Agent(五)

发表于 2026-07-18 更新于 2026-07-23 分类于 计算机
Multi-Agent 拓扑设计四步、三种 canonical 模板、理论→框架映射（主三+巡览占位）、实践阶梯；收口至 Deep Agents。

接 Multi-Agent（四）：角色、协作、通信已齐；本篇讲 拓扑设计方法、三种 canonical 模板、理论→三框架映射 canonical 表，并收口本系列。

0. 本篇位置

（一）～（四）为理论层；（五）为 设计方法论 + 映射收口 + 实践阶梯。

完整「理论→三框架」对照 只在本篇 §4 维护；实现框架对比 §5、CrewAI / Deep Agents 系列正文 只回链此处，不重写全表。

1. 拓扑设计四步

每步产出物：

步骤 产出 验收问题
角色 角色表 + 工具边界 + 验收标准 能否删掉某角色而不丢能力？
协作 顺序图或状态机草图 是否可退回单 Agent？
通信 State Schema / 事件表 并行写是否安全？
治理 Checklist 映射 Agent（四）§6 假完成能否被 Gate 拦住？

2. 三种 canonical 拓扑模板

2.1 研究流水线（Role-Based + Message Passing）

  • 协作： Role-Based + 可选 Voting 校验
  • 通信： Worker 摘要 Handoff；证据指针进 Store
  • 实现： LangGraph L2；或 CrewAI sequential Crew

2.2 企业审批流（Hierarchical + Event Bus + HITL）

  • 协作： Hierarchical + Role-Based
  • 通信： Event Bus 驱动步骤；关键 state 持久化
  • 实现： LangGraph interrupt + CrewAI Flow @human_feedback

2.3 并行投票校验（Voting + Shared Memory）

  • 协作： Voting
  • 通信： Shared Memory 写入各 Worker 结论；聚合只读
  • 实现： LangGraph Send + Reducer

3. 与 LE Gate、发版 Checklist 对齐

Multi-Agent 上线 不降低 Agent（四）§6 标准：

域 Multi-Agent 额外关注
Loop/Agent 每 Worker Task Success；Supervisor 假完成
Context Handoff 后约束完整性；子 Trace 不灌主窗
安全 Worker 工具白名单；并行租户 namespace
成本 角色数 × 轮次；Voting N 倍成本
可观测 节点/角色级 Trace（非仅最终回答）

选型口诀（与 实现框架对比 §5 一致）：

  • 每步图级门禁、复杂 handoff → LangGraph
  • 快速委托重 research、主 context 要干净 → Deep Agents Subagent
  • Researcher + Writer + Editor 角色团队 → CrewAI sequential
  • 借鉴 Debate 群聊模式 → AutoGen 巡览；生产实现仍优先主路径

5. 实践阶梯（LangGraph 为主）

不重复 LangGraph（六） 教程；只给 理论验收导向 的阶梯：

级别 目标 验收
L0 Router → 2 Worker → 聚合 Handoff 含证据指针；Trace 可复盘
L1 Supervisor + Checkpointer + Store 子任务失败可局部重试；interrupt 可恢复
L2 混合拓扑 + LE Gate + 成本记录 Agent（四）§6 相关项全绿

退回单 Agent 信号： 仅增加角色名、无独立工具/状态/验收；Token 升而成功率不变；Supervisor 与 Worker 职责重叠。
