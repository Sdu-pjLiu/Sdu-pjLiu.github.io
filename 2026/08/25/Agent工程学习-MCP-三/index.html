AI-Agent工程学习-MCP(三)

发表于 2026-07-21 更新于 2026-07-23 分类于 计算机
langchain-mcp-adapters、create_agent/create_deep_agent 挂载 MCP；allowlist、多 Server、Resources 注入。

接 MCP（二）：Server 就绪后，用 Client 把 MCP 能力挂进 LangChain / Deep Agents Harness——扩展 Deep Agents（二）§1.2 示例。

0. 本篇位置

1. langchain-mcp-adapters

包：langchain-mcp-adapters（与 Deep Agents 文档一致）。

HTTP 远程 Server：见 Deep Agents 二 url + transport: http 配置。

2. 挂载 create_agent

步骤：

  1. Client get_tools() → LangChain tools 列表
  2. 可选 filter：只保留 allowlist 内 name
  3. create_agent(model, tools=[...本地..., *mcp_tools])
  4. invoke({"messages": [...]})

MCP Tool 与本地 @tool 并列；模型见统一 Schema。description 合并后须无歧义（必要时 Client 加前缀 seo__crawl_url）。

3. 挂载 create_deep_agent

与 Deep Agents（二） 相同：create_deep_agent(..., tools=mcp_tools)。

注意：

  • MCP tools 与内置 read_file / write_todos 等 并存
  • 写工具配 interrupt_on（Deep Agents 五）
  • 大 Observation 走 FS offloading（Deep Agents 三）

4. allowlist 与 Middleware 二次校验

MCP 动态发现 不等于 全部交给模型：

对齐 Agent（六）权限三档：自动 / 确认 / 禁止。

LangChain HumanInTheLoopMiddleware 可对 MCP 写操作 interrupt_on。

5. 多 Server 与命名冲突

MultiServerMCPClient 配置多 key：

冲突策略：Client 重命名 server_key__tool_name 或按 Server 分 Agent。Trace 须记录 哪个 Server 被调用。

6. Resources → Context 注入

Resources 不经过 tool_call 时，由 Host/Runtime 在 invoke 前：

须校验 URI 与 tenant 匹配；防恶意 Server 返回 Injection（MCP 四）。

7. L1 联调实验

  1. 启动 MCP（二）L0 stdio Server
  2. MultiServerMCPClient + create_agent
  3. 用户问：「调用 echo_tool 回显 hello」
  4. Trace 可见 tool_call → ToolMessage → Final

验收：call_id 对齐；非法 tool 名被 Runtime 拒绝。
