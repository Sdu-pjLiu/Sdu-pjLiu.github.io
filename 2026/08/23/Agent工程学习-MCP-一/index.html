AI-Agent工程学习-MCP(一)

发表于 2026-07-21 更新于 2026-08-20 分类于 计算机
MCP 开篇：Host/Client/Server、Tools/Resources/Prompts、传输；与 Agent（六）认名及 Harness 映射。

接 RAG（五）：Knowledge 层用 RAG 深化后，外部能力（爬虫、SEO、数据库、SaaS）宜通过 Model Context Protocol（MCP） 标准接入——本篇讲 架构与协议；实现见（二）Server、（三）Client。

0. 本系列在学习路径中的位置

理论认名：Agent（六）§2 MCP — Tools / Resources / Prompts 与 Tool Calling 闭环关系。

Client 示例：Deep Agents（二）§1.2 — MultiServerMCPClient 异步挂载。

本系列分工： 不重定义三件套；专注 协议、自建 Server、LangChain/Deep Agents 集成、安全与 SEO 项目。

篇 覆盖
（一） 架构、传输、调用序列
（二） Server 开发
（三） Client + Agent 框架
（四） Auth/安全 + SEO 项目

官方：Model Context Protocol · LangChain MCP

1. MCP vs 自建 Tool vs OpenAPI

方式 适用
函数 @tool 单应用、逻辑简单、无复用
OpenAPI HTTP 已有 REST 服务
MCP Server 跨应用复用、IDE+Agent 统一接入、第三方能力包

MCP 不替代 Runtime 校验——仍须 Schema、权限、HITL（Agent 六）。

2. Host / Client / Server

角色 职责
Host 承载 Agent 的应用（Cursor、自研控制台）
Client 按 MCP 协议连接 Server、发现能力、转发调用
Server 暴露 Tools/Resources/Prompts；执行真实逻辑

生命周期：initialize → list_tools / list_resources → call_tool / read_resource → （可选）shutdown。

3. Tools / Resources / Prompts（Server 侧）

回链 Agent（六）：

MCP Server 暴露 Agent 侧
Tools 可调用动作 + JSON Schema → 模型 Tool Schema → Invocation
Resources URI 可读内容 → 读入 Context（未必走 tool_call）
Prompts 参数化模板 → 复用 PE Registry 思想

执行闭环仍是：模型提案 → Runtime 校验 → Server 执行 → Result 写回 ToolMessage。

4. 能力发现

Client 启动时：

  1. list_tools → 转为 LangChain StructuredTool 列表
  2. list_resources → 供 UI 或 Runtime 预读
  3. list_prompts → 可选注入

工具名冲突（多 Server）→ Client 侧 前缀 或 allowlist（MCP 三）。

5. 传输：STDIO 与 HTTP

传输 场景
STDIO 本地子进程 Server；开发、CLI、IDE
Streamable HTTP 远程 Server；生产、多租户
SSE 旧版 HTTP+SSE 双端点传输 为兼容认名；新项目以官方当前 Transport（Streamable HTTP）为准。注意：传输层弃用 ≠ 禁用 SSE 技术本身——Streamable HTTP 响应仍可能用 SSE 流式下发事件

initialize / capability 协商等握手细节以 MCP 现行 spec 为准，实现演进时请核验。

Deep Agents 示例用 HTTP URL；本地 SEO Server 常用 stdio（MCP 四）。

6. Harness Tool 层映射

Agent（三）§6 Harness Tool 层：

MCP 在 Tool 层之下 的标准总线；Orchestration 仍在 LangGraph。

7. 完整调用序列

Resources 路径：read_resource(uri) → 注入 system/context 不经过 tool_call 环，仍须权限控制。

总结

架构：Host–Client–Server；能力三件套。

传输：stdio 本地；HTTP 远程。

映射：MCP → Harness Tool 层；不替代 Runtime。
