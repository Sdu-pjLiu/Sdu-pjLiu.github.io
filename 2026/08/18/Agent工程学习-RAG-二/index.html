AI-Agent工程学习-RAG(二)

发表于 2026-07-20 更新于 2026-08-20 分类于 计算机
Hybrid/Rerank/Query/Multi-Query/Compression/Parent Document/Metadata 检索增强；选型与降级。

接 RAG（一）：朴素 similarity 有 baseline 之后，按 可测瓶颈 叠加检索增强——不默认「全上」。

0. 本篇位置

回链：LangChain（四）§3 已认名；本篇写 选型、组合与 LangChain 集成思路。

1. 增强模式总览

失败症状 优先尝试
专名、编号、SKU 检不到 Hybrid Search
召回多但 Top-K 噪声大 Reranker
用户问法与文档措辞差 Query Rewrite / Multi-Query
检索块太长撑爆 Context Contextual Compression
小块准但缺段落上下文 Parent Document Retrieval
多租户、多版本文档混库 Metadata Filtering

原则：每次只加一种增强，在同一评测集上对比（RAG 一 L0 集）。

2. Hybrid Search

向量 擅语义；BM25/关键词 擅 exact match。

LangChain 侧常见：EnsembleRetriever 组合多个 Retriever，或向量库原生 hybrid（视后端而定）。

适用：产品型号、法规条文号、内部代号、中英混排术语。

关键词一路的引擎工程（倒排、mapping、与向量对照）见 Elasticsearch 学习。

3. Reranking

参数 建议
K₁ 够召回即可；过大增延迟
K₂ 进 Prompt 的条数；对齐 Context 预算

Rerank 解决「召回了但排序错」；不能替代 Hybrid 解决「压根没召回」。

4. Query Rewrite 与 Multi-Query Retrieval

Query Rewrite： LLM 将口语问题改写成检索友好表述（含关键词、实体）。

Multi-Query： 一次生成多条 query，分别检索后 去重合并（与 Expansion 同类工程目标）。

注意：改写增加 一次 LLM 调用；需计入 Budget（Agent 三 Budget）。

5. Contextual Compression

检索块常含无关句。Compression 在进 Prompt 前抽取与 query 相关的句/段。

与 Agent（五）Context 压缩 对齐：硬规则、合同字段不可压没；只压检索冗余。

LangChain：ContextualCompressionRetriever + DocumentCompressor（如 LLMChainExtractor）。

6. Parent Document Retrieval

适用：法条、API 文档——小块定位准，但回答需要整节定义。存储需 parent_id 或原文指针 metadata。

7. Metadata Filtering

检索 前 过滤（非生成后过滤）：

常见维度：tenant_id、department、effective_date、language、classification。与 RAG（五）ACL 衔接。

8. 降级策略

情况 降级
Rerank 服务超时 仅用初检 Top-K
Hybrid 一路为空 回退纯向量
Rewrite 产出空 query 用原问
全链路无 chunk 过阈值 拒答 或转人工，禁止编造

增强是 可选插件，不是单点故障源。

8.1 生产默认组合与降级顺序

推荐默认（企业知识库）：

何时关 Rerank： P95 延迟破 SLO、Rerank 服务不稳定、FAQ 类问题 Hybrid Top-K 已够用。关之前用同一黄金集对比 Recall 与人工质量。

降级顺序（故障时）： Rerank 超时 → 仅 Hybrid；Hybrid 一路空 → 纯向量；Rewrite 失败 → 原问；仍空 → 拒答/转人工。

9. L1 实验

在 RAG（一）同一 10 问评测集 上对比：

  1. Baseline：similarity Top-4
    • Hybrid
    • Rerank
    • Metadata filter（若多租户）

记录 Recall@4、P95 延迟、单次 query 成本；选 收益/成本比最高 的组合写入生产默认配置。

总结

Hybrid：专名 + 语义；Rerank：精排降噪。

Query / Multi-Query：措辞鸿沟；Compression：省窗位。

Parent Doc：小块定位、大块生成；Metadata：租户与类型隔离。

降级：增强失败回朴素 similarity 或拒答。
