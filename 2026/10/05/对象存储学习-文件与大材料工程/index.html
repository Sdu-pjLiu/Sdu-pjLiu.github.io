对象存储学习-文件与大材料工程

发表于 2026-08-07 更新于 2026-08-20 分类于 计算机
对象存储定位、上传下载与预签名、生命周期与权限、与 Agent/RAG/K8s 大材料外置对齐。

Agent、RAG、K8s 多处假设「材料不进本地盘」。本篇收 对象存储工程口径：何时用、怎么传、权限与生命周期如何定。

回链： Agent 工程化（四）Serverless · RAG 五 Ingestion · K8s · 一致性

1. 是什么：对象 vs 文件 vs Blob 列

对象存储 块/本地盘 DB
单位 bucket + key（对象） 文件路径 行
适合 大文件、不可变版本、海量 低延迟本地 IO 元数据与事务
访问 HTTP API / SDK POSIX SQL

典型： 用户上传、PDF 知识库源、Agent 工件、备份、静态资源（可加 CDN）。

注意点： 对象存储 不是 强一致事务日志；元数据（谁拥有、ACL、业务状态）仍在 DB。

3. 权限与多租户

硬闸： 与 鉴权多租户 相同——不能靠「猜到 key 就能下」；列举权限严控。

注意点： public-read 桶 + 可枚举前缀 = 事故；预签名过长 = 泄露窗口。

4. 生命周期与版本

策略 用途
TTL / 过期删除 临时工件、预览
转低频 / 归档 冷数据降本
版本控制 防误删；配合 RAG index_version
删除同步 源删 → 删对象 + 删向量索引（RAG 五）

5. 与一致性、队列

「DB 记已上传 + 对象已存在」：

5.1 CDN 边界

对象存储 CDN
职责 源站、权威对象 边缘缓存加速 读
写 仍走预签名/SDK 写源 不经 CDN 写（除非专用上传域）
失效 删对象 / 改 key 需 purge 或短 TTL

静态站点可「OSS + CDN」；带鉴权的私有文件仍以短时预签名为主，勿把 private 对象长期挂在公开 CDN。

与 Agent 工程化（四）「无本地盘假设」：Worker/Serverless 产物写本篇对象存储，Checkpoint 只留 object_key。

6. 自检（短）

S1. 为何大文件用预签名而不是经 API 中转？

推荐回答： 省应用带宽与超时风险；API 只做鉴权与签发；完成后再写元数据。

S2. 对象 key 与租户如何防越权下载？

推荐回答： key 含 tenant 前缀 + DB 校验归属 + 短时预签名；禁止永久 public 列举。

I1. Agent 生成长报告如何存？

推荐回答： Worker 写 OSS；Checkpoint/消息只存 object_key；下载经鉴权预签名；TTL 与租户隔离。

总结

对象存文件，DB 存权威元数据；预签名控权；生命周期与 RAG/遗忘删除联动。
