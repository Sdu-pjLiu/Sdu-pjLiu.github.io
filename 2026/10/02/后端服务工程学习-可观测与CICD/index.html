后端服务工程学习-可观测与CICD

发表于 2026-08-07 更新于 2026-08-20 分类于 计算机
业务服务日志/Metrics/Trace（链 OTel，区分 Agent Run）；CI：build→test→image→K8s；配置与密钥。

接 认证鉴权。本篇收 业务 HTTP 服务怎么看见、怎么安全发布；容器怎么跑见 Docker/K8s，Agent 轨迹见工程化（二）。

0. 本篇位置与边界

做 不做
日志 / Metrics / Trace 三联；OTel 认名 某一 APM 厂商独家向导
CI：build→test→image→部署门禁 云控制台逐步截图
配置与密钥分层 服务网格全功能

口径钉死：

本篇 已有
观测对象 HTTP/业务服务、作业 Agent 工程化（二） = Agent Run Trace/成本
运行 — Docker · K8s
发布 流水线与门禁 K8s = 编排与探针；本篇 = 谁在何时允许上线

关联：request_id / trace_id 可与 Agent run_id 并列出现在同一请求链路。

机器与内核视角的排查路径见 Linux 性能。

1. 日志

是什么： 结构化事件流，供检索与审计，不是 print 堆栈聊天。

字段 用途
timestamp / level 排序与过滤
request_id / trace_id 与 Trace 关联
tenant_id / user_id（可哈希） 多租户排障
msg + 业务键 人读与聚合

注意点： 禁止落密钥、Token、完整身份证号；采样高基数路径防打爆存储。

2. Metrics

最小 RED/USE 意识：

类 示例
流量 QPS、并发
错误 5xx 率、业务错误码率
延迟 P50/P95/P99
饱和 队列深度、连接池、CPU

告警挂在：错误率突增、P95 破 SLO、依赖 5xx、饱和——与 Agent 熔断 同类思维，对象换业务依赖。

2.1 SLO 与告警决策

项 示例口径
SLI 成功请求占比；P95 延迟
SLO 月成功 ≥ 99.9%；核心写接口 P95 < 300ms
告警 燃烧过快（短窗错误率）+ 慢燃（长窗 SLO 危险）
降噪 依赖已知故障时抑制下游告警；分页/on-call

注意点： 只告 CPU 不告业务错误码 → 假平静；无请求_id 维度 → 无法下钻。

3. Trace 与 OpenTelemetry

项 口径
OTel 跨语言 Trace/Metrics/Log 信号标准
与 Agent LangSmith 等看 Run 内部；OTel 看服务间；用 ID 关联，不互相替代
采样 生产常头部采样；错误强制保留

4. CI/CD 流水线

门禁 含义
测试失败 禁止出包
镜像不可变 tag 可回滚到摘要
配置与代码分离 见 §5
迁移 DB migrate 顺序与回滚策略写清

与 K8s：流水线产出的是 可部署制品 + 清单；探针与 PDB 见 K8s 篇。

4.1 发布、金丝雀与回滚

决策 条件
继续放量 金丝雀窗口内错误率/延迟不劣于基线
回滚 5xx 或业务错误码突增；关键路径 P95 破 SLO
冻结发布 依赖故障、变更窗口外

4.2 DB 迁移与发布顺序

变更类型 顺序
兼容加列 / 新索引 migrate 先于或同发读新列的代码
删列 / 改义 先发不再读写旧列的代码 → 再 migrate 删除
危险锁表 低峰、在线 DDL 策略、可回滚脚本

反模式： 先删列再发仍读该列的旧 Pod；migrate 与代码绑死无法单独回滚。

5. 配置与密钥

类型 放哪
密钥 / DB URL / 第三方 Token 密钥管理 / K8s Secret / 环境注入；不进 Git
非敏感默认 代码常量（超时、重试次数）
环境差异 配置中心或 per-env values

轮换：双密钥过渡窗口；Agent/MCP Client 配置同步更新——见 MCP（四）。
