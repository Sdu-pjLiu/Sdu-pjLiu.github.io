基础设施学习-自检面试与对照

发表于 2026-08-07 更新于 2026-08-20 分类于 计算机
网关限流、对象存储、Elasticsearch、Linux 性能自检 S/I、checklist 与外链；收口基建四篇。

学完 网关限流 · 对象存储 · Elasticsearch · Linux 性能 后，用本篇遮答验收。

0. 使用说明

  1. 先遮住「推荐回答」自述。
  2. 过关：能设计多租户写接口限流；能口述大文件预签名；能说明 Hybrid 里 ES 与向量分工；能按 us/wa 分层排障。
  3. 上游：后端自检 · 一致性。

1. 网关与限流

S1. 令牌桶与漏桶差在哪？本地限流多副本有何问题？

推荐回答： 令牌桶允许有限突发；漏桶更恒定流出。多副本本地计数会使放行约 N 倍；共享配额用 Redis。见网关 §2–§2.1。

S2. 多租户限流最少几层？429 契约要点？

推荐回答： IP 粗限 → 鉴权后租户/用户 → 写路由更严；429 + Retry-After + 稳定 code。

I1. 开放平台被一家租户打满怎么改？

推荐回答： 按 tenant/API Key 独立配额；观测分租户 QPS；超额 429；必要时隔离或降级。

2. 对象存储

S3. 为何大文件用预签名？完成确认做什么？

推荐回答： 省应用带宽与超时；API 鉴权签发；客户端直传后确认 + Head 校验再写 DB。见 OSS §2.2。

S4. multipart 未 Complete 前能否当完整对象读？

推荐回答： 通常不能；中断应 Abort 或生命周期清理未完成分片。

S5. 对象 key 如何防越权？CDN 适合私有文件吗？

推荐回答： tenant 前缀 + DB 归属 + 短时预签名；私有文件勿长期公开 CDN。

I2. Agent 长报告如何存？

推荐回答： Worker 写 OSS；Checkpoint 只存 object_key；下载鉴权预签名；对齐工程化四。

3. Elasticsearch

S6. text 与 keyword？tenant 放哪？

推荐回答： text 分词全文；keyword 精确过滤/聚合；tenant_id 用 keyword 且 filter 硬闸在检索前。

S7. 为何避免巨大 from？刚写入立刻搜不到？

推荐回答： 用 search_after（按稳定 sort 取上一页最后值）；refresh 近实时窗口，非提交即读。最小 DSL 见 ES §3.0。

S8. Hybrid RAG 里 ES 角色？

推荐回答： 关键词召回 + filter；与向量互补再融合/Rerank。见 RAG 二、ES §4。

I3. 源 PDF 更新后 ES 与向量如何一致？

推荐回答： 同 source_id 增量更新/删除；别名切版本；对账。对齐 RAG 五。

4. Linux 性能

S9. iowait 高说明缺 CPU 吗？急救包命令？

推荐回答： 否，在等 IO。急救：uptime、free、mpstat、iostat、ss。见 Linux §6–§7。

S10. 节点空但 Pod 慢先看啥？

推荐回答： Trace/依赖；再 cgroup limit 与 kubectl top/describe throttle/OOM。

I4. K8s 上 MySQL 延迟升高如何分层？

推荐回答： 慢查询与锁 → iostat/wa → PVC/云盘 → 同节点噪声 → 参数。

5. Checklist

  • 能画 IP→租户→写路由限流与 429
  • 能画预签名上传五步 + 对账
  • 能说明 ES filter(tenant) + Hybrid（bool must + term filter DSL）
  • 能区分 us 忙与 wa 等 IO
  • 能口述集群 green/yellow/red 决策一句
